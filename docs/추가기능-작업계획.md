# 추가 기능 작업 계획

작성일: 2026-10-28

## 범위

제안한 기능을 모두 적용한다. 애니메이션, 화면 전환 효과, 동영상 재생은 범위에서 제외한다.

## 기능 목록

### 1단계: 슬라이드 쇼 기본 기능

| # | 기능 | 동작 | 단축키 | 수정 파일 |
|---|---|---|---|---|
| 1 | 화면 가리기 | 검은 화면 / 흰 화면으로 덮는다. 같은 키를 다시 누르거나 다른 이동 키를 누르면 해제한다. 흰 화면에서도 판서할 수 있다. | B, W (`.` `,`도 같은 동작) | ShowWindow |
| 2 | 레이저 포인터 | 마우스 위치에 빨간 점을 표시하고 커서를 숨긴다. 판서 도구와 동시에 쓰지 않는다. | Ctrl+L | PenState(Tool.Laser), ShowWindow |
| 3 | 번호로 이동 | 숫자를 입력한 뒤 Enter를 누르면 해당 슬라이드로 이동한다. 입력 중인 번호를 화면에 표시한다. 쇼에서는 숫자 키가 색 선택 대신 번호 입력으로 쓰인다. | 숫자 + Enter | ShowWindow, MainWindow(HandleCommonKey) |
| 4 | 판서 되돌리기 | 현재 슬라이드의 마지막 획을 지운다. 편집 화면에서는 판서가 있으면 판서 되돌리기, 없으면 기존 편집 되돌리기로 동작한다. | Ctrl+Z | MainWindow, ShowWindow |
| 5 | 커서 자동 숨김 | 포인터 모드에서 마우스를 3초 움직이지 않으면 커서를 숨긴다. | - | ShowWindow |
| 6 | 시계와 경과 시간 | 쇼 화면 오른쪽 아래 쪽번호 옆에 현재 시각과 쇼 시작 후 경과 시간을 흐리게 표시한다. | - | ShowWindow |

### 2단계: 발표자 보기

| # | 기능 | 동작 |
|---|---|---|
| 7 | 발표자 보기 | 쇼를 시작하면 쇼 모니터가 아닌 모니터(보통 노트북 화면)에 발표자 창을 띄운다. 현재 슬라이드(판서 가능), 다음 슬라이드, 발표자 노트, 경과 시간, 현재 시각, 쪽번호, 이전/다음 버튼을 표시한다. 모니터가 하나뿐이면 띄우지 않는다. 슬라이드 쇼 탭에 "발표자 보기 사용" 체크박스를 둔다. |

- 발표자 노트는 `NotesSlidePart`에서 본문 자리 표시자(type="body")의 텍스트를 읽는다.
- 키 입력은 쇼 창과 같은 처리기를 사용한다.
- 신규 파일: PresenterWindow.xaml/.cs

### 3단계: 판서 강화

| # | 기능 | 동작 | 단축키 |
|---|---|---|---|
| 8 | 빈 판서 페이지 | 현재 슬라이드 뒤에 빈 슬라이드를 넣고 이동한다. 파일에 실제 슬라이드로 추가되므로 저장 여부는 기존 저장 흐름을 따른다. | Ctrl+Enter (쇼, 편집 모두) |
| 9 | 직선 보정 | Shift를 누른 채 그린 획은 시작점과 끝점을 잇는 직선으로 바꾼다. | Shift + 드래그 |
| 10 | 화면 확대 | 드래그한 영역을 쇼 화면 전체로 확대한다. Esc 또는 클릭으로 원래 크기로 돌아온다. 확대 중에도 판서할 수 있다. | Z |
| 11 | 판서 자동 보관 | 판서가 바뀌면 `%LOCALAPPDATA%\PptSlider\ink\<파일 경로 해시>.isf`에 슬라이드별 획을 저장한다. 같은 파일을 다시 열면 복원한다. 슬라이드는 SlideId로 구분한다. | - |
| 12 | PDF 내보내기 | 모든 슬라이드를 판서 포함(또는 제외)으로 PDF 파일로 저장한다. 판서 포함 여부는 저장할 때처럼 묻는다. | 파일 메뉴 |

- PDF: 새 패키지를 추가하지 않는다. WPF `RenderTargetBitmap`으로 슬라이드를 이미지로 만든 뒤, JPEG 스트림을 넣은 최소 PDF를 직접 작성한다(페이지당 이미지 1장, 약 60줄). 텍스트 선택은 되지 않는다.

### 4단계: 뷰어 완성도

| # | 기능 | 동작 |
|---|---|---|
| 13 | SmartArt 표시 | SmartArt의 `graphicFrame`에서 `dgm:relIds`를 찾고, 연결된 DiagramPersistLayoutPart(drawing.xml)의 `dsp:spTree`를 기존 도형 그리기 코드로 렌더링한다. 저장된 drawing이 없는 파일은 지금처럼 안내 문구를 표시한다. |
| 14 | 최근 파일 목록 | 최근에 연 파일 10개를 `%LOCALAPPDATA%\PptSlider\recent.txt`에 보관한다. 홈 탭의 열기 버튼 옆 드롭다운과 빈 화면 안내에 표시한다. |
| 15 | 자동 저장/복구 | 편집 내용이 있으면 2분마다 `%LOCALAPPDATA%\PptSlider\autosave\`에 사본을 저장한다. 정상 종료하면 사본을 지운다. 다음에 같은 파일을 열 때 사본이 원본보다 새로우면 복구할지 묻는다. |

## 단축키 변경 요약

| 키 | 기존 | 변경 후 |
|---|---|---|
| B, W | 없음 | 쇼: 검은/흰 화면 |
| Ctrl+L | 없음 | 레이저 포인터 |
| Ctrl+Z | 편집 되돌리기 | 판서가 있으면 판서 획 되돌리기 우선(편집 화면), 쇼에서는 판서 되돌리기 |
| Ctrl+Enter | 없음 | 빈 판서 페이지 삽입 |
| Z | 없음 | 쇼: 화면 확대 |
| 숫자 키 | 펜 색 | 편집 화면: 펜 색 (그대로) / 쇼: 숫자+Enter는 이동, 숫자만 누르고 1초 지나면 펜 색 |

쇼에서 숫자 키는 번호 이동과 펜 색 선택이 겹친다. 숫자를 누른 뒤 1초 안에 Enter나 다음 숫자가 오면 번호 입력으로, 아니면 펜 색으로 처리한다.

## 검증 방법

- 각 단계마다 `dotnet build`가 경고 없이 통과해야 한다.
- `--selftest`에 다음 항목을 추가한다: 발표자 노트 읽기, SmartArt 렌더링 도형 수, 판서 보관 후 복원, PDF 파일 생성(헤더와 페이지 수 확인), 빈 슬라이드 삽입.
- 사용자 교재(`01_환경 설정.pptx`, `07_Jenkins.pptx`)로 렌더링 PNG를 확인한다.
- 쇼 화면 기능은 테스트 창에만 키를 보내 확인한다(포그라운드 창이 테스트 창인지 확인한 뒤 입력).
- 발표자 보기는 이 PC에 모니터가 하나뿐이라 실제 2화면 동작은 확인할 수 없다. 테스트용으로 같은 모니터에 창을 띄우는 옵션으로 화면 구성만 확인한다.
- 각 단계를 마치면 빌드 결과가 `bin\Debug`에 실제로 반영되었는지 확인한다. 앱이 실행 중이면 사용자에게 앱을 닫아 달라고 요청한다.
