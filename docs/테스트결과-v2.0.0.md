## 4. 발견된 결함과 조치

### D-1. `loc:` 검사가 리팩토링 이후 실행 위치에 따라 검사를 건너뛰거나 오탐함 (테스트 코드 결함, 수정 완료)

**현상**

리팩토링 중에는 빌드 출력을 임시 폴더에 두고 자체 테스트를 돌렸습니다. 이 경우 소스 폴더를 찾지 못해 `loc:` 키 검사가 "0 keys"로 사실상 건너뛰어졌습니다.

정식 출력 폴더(`bin\Debug\net10.0-windows`)에서 실행하자 다음 오류가 나왔습니다.

```
FAIL loc: 273 keys used in the source all exist — missing: shape.
```

**원인**

도형 갤러리는 이름 키를 코드에서 조립합니다(`L.T("shape." + kind)`). 키 탐색 정규식이 이 조립 코드의 `"shape."`를 하나의 완결된 키로 읽었습니다. 앱 동작의 결함은 아닙니다.
